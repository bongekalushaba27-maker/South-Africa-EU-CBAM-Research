# GEMPACK and GTAP-E Modelling

This folder contains computational modelling materials associated with the South Africa–EU CBAM research.

The research uses the GTAP-E framework to examine the economy-wide implications of alternative CBAM and domestic carbon pricing scenarios.

## Modelling Components

- GTAP database preparation and aggregation.
- Regional and sectoral aggregation.
- CBAM policy shock implementation.
- Domestic carbon pricing scenarios.
- Model simulations and outputs.
- Documentation of modelling assumptions and procedures.

## Software

- GEMPACK
- GTAP-E
- GTAP Database

Note: Proprietary and licensed GTAP database files are not included in this public repository.
