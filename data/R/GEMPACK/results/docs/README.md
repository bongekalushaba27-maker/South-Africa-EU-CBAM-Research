# Research Documentation

This folder contains the research documentation supporting the South Africa–EU CBAM analysis.

## Documentation

- Research methodology.
- Research objectives and questions.
- GTAP-E model specification.
- Data sources and descriptions.
- Sectoral and regional aggregation.

- Carbon pricing scenario assumptions.
- Technical notes and model limitations.

The documentation aims to ensure transparency, reproducibility and methodological consistency throughout the research process.
